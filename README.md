# 💸 Simple Payments App

A basic MERN stack (MongoDB, Express.js, React, Node.js) web application that allows users to sign up, log in, and securely transfer funds to others on the platform. Each user is randomly assigned a starting balance upon registration. The app includes essential features such as user search, account editing, and account deletion.

---

## 🚀 Features

- **User Authentication**
  - Sign Up with email and password
  - Secure Sign In
- **Account Dashboard**
  - View current balance
- **Fund Transfer**
  - Send money to any registered user on the platform
- **User Management**
  - Edit account information (name, password, etc.)
  - Delete account
  - Search for other users to send money

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Axios, Tailwind
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (via Mongoose ODM)
- **Authentication:** JSON Web Tokens (JWT), bcrypt for password hashing
